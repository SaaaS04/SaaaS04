### [Monitor de Juros dos Bancos](https://github.com/SaaaS04/Monitor_de_juros) <sub><sup>⭐ DESTAQUE</sup></sub>
Pipeline ETL que coleta as taxas de juros de cada banco na API de dados abertos do **Banco Central** e responde: *qual banco cobra mais caro? Bancos digitais cobram menos?*

- **Extrai** da API Olinda → **trata** com Pandas → **carrega** no PostgreSQL (Docker)
- Camadas bronze → prata → ouro: JSON bruto → Parquet → tabelas de análise
